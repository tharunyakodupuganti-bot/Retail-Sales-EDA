# Retail Sales EDA

## Project Overview
Exploratory Data Analysis of retail transactions using Python, pandas, matplotlib and seaborn.

## Files
- `Retail_Sales_EDA_Project.ipynb` — complete analysis notebook with markdown, code, charts and observations.
- `retail_sales_dataset.csv` — dataset used for the analysis.
- `requirements.txt` — Python packages required to run the notebook.

## How to Run
1. Open the folder in VS Code.
2. Install the requirements.
3. Open `Retail_Sales_EDA_Project.ipynb`.
4. Select a Python kernel.
5. Run all cells.

## Dataset Note
The dataset contains Product Category but no individual Product Name/SKU. The notebook therefore uses a transparent `Product Category + Price per Unit` product-variant proxy for the Top-10 analysis rather than inventing product names.
